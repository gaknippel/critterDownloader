# critterDownloader

a simple YouTube video and audio downloader.

<div align="center">

![Critter Logo](public/critterDownloaderAd.gif)

</div>

## features

- downloading video & audio in the BEST quality
- no subscriptions
- simple ui/ux
- no dumb ads
- ability to save to path
- changeable themes

## installation

download the latest release and run the installer.

https://github.com/gaknippel/critterDownloader/releases

## usage

1. paste a YouTube link
2. choose video or audio
3. click download! easy!

## built with

- tauri
- react
- yt-dlp
- ffmpeg
- shadcnui
- reactbits
